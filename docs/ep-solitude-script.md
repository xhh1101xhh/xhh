## 附 2｜自查

- **转场**（共 15 次，没有任何一种用了两次）：升降镜头 f3 → 快速竖摇 f258 → 剪纸层层钻入 f576 → 横推 f1021 → 拱形遮罩 f1276 → 钻进灯罩（虹膜开）f1530 → 门板擦屏 f1785 → 形状匹配 + 金线描景 f2039 → 镜面翻转 f2548 → 甩镜 f2803 → 纸张撕裂 f3057 → 上下分屏合拢 f3184 → 光点闪光 f3311 → 斜向光切 f3566 → 金光虹膜收 f3955。开场转场和结尾转场不同。本期是首期，没有往期可撞。
- **砸屏**全部落在四个主爆点上：f512 / f2548 / f3057 / f3566。
- **底色**：午夜蓝 → 靛蓝 → 焦糖棕 → 暮橙 / 赭红 → 深玫瑰 / 琥珀 → 墨绿 / 深青 → 暗紫 / 灰紫 / 墨紫 → 破晓暮橙 / 晨光金 → 墨黑配金 → 午夜蓝配金（结尾和开头呼应）。超过 5 种，相邻两节色相都不同。
- **人物表情线**：警觉 → 得意 → 发空 → 僵住、烦躁、狼狈 → 心动又退缩 → （孩子）专注、惊吓、安心 → 平静 → 疑惑 → 冷淡、不耐烦、缩成一团、泪光 → 坚定 → 惊叹、害羞、大笑 → 平静温暖。全程没有同一张脸。动作没有连续两屏重复：叉腰、抱臂、挥手都隔开出现。
- **元素跨类**：自然（海、月、云、风暴、星、海鸥）· 生活（床、杯、牙刷、碗、书架、手机剪影、椅子、保温壶）· 建筑（灯塔、码头、公寓、穹顶）· 动物（寄居蟹、海鸥）· 几何（天平、温度计、拱窗）· 光与粒子（光束、渔火、光尘、心灯）· 手绘符号（问号、乌云、箭头、波浪线）。没有一类撑满全片。
- **贯穿物件跟论点变**：只照自己 → 外人进门时变冷蓝 → 钻进去成了回忆 → 隔壁那盏同款灯 → 变成心灯 → 被壳罩住 → 裂开 → 金缮修好 → 挂在码头 → 收成金点。
- **金线四处**：f2039 / f3057 / f3407→f3693 / f3955→f4067。
- **小剧情或小实验**，每节至少一个：S0 有船来就关灯；S1a 往屋里加一个人；S1b 平行宇宙 + 寄居蟹缩壳；S2 起风了，孩子回头看光；S3 孤独小乌云来了不慌；S4 三次靠近和温度计、壳长成穹顶；S5 推开穹顶开灯、搬第二把椅子；S6 送走朋友后仍然"不空"，又迎来下一只船。
- **结尾**：没有任何互动引流；结论 + 金光余韵，落在结束音上。和开头呼应：同一构图、同一只挂灯小船、灯从"关"到"一直亮着"、挥手动作对调。
- **事实表述**：只用"在他看来""温尼科特……提过"；不写诊断标签；用"爱安静不等于有壳"做平衡；不画婴儿，孩子是学龄前，妈妈只出背影；主角始终在有栏杆的阳台或码头上，不出现俯视大海的孤立镜头。
- **右侧零文字**：门铃、温度计、名片、闹钟、说话波浪线都在左侧，而且多数是图标。

- 第 51 屏（码头上下分屏）：上半屏是他独自看书，下半屏只有朋友的船靠岸，没有他。合拢后才变成同一画面，他起身招手。
